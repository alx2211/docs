2. The Asynchronous Event Loop (Kafka Backbone)

AI reasoning takes time (sometimes 2 to 5 seconds per model call). Therefore, you cannot block the main HTTP thread. You use Kafka to handle the state transitions of the agent asynchronously.
java
@Component
public class AIAgentEventListener {

    private final ChatLanguageModel chatModel; // Injected via OCI GenAI or AWS Bedrock
    private final PaymentAgentTools paymentTools;
    private final KafkaTemplate<String, Object> kafkaTemplate;

    @KafkaListener(topics = "payment-initiation-events", groupId = "ai-orchestrator")
    public void processAgentLoop(ConsumerRecord<String, String> record) {
        String userRequest = record.value();
        
        // Assistant orchestrator wraps the LLM with the deterministic Java tools
        var assistant = AiServices.builder(PaymentAssistant.class)
            .chatLanguageModel(chatModel)
            .tools(paymentTools)
            .chatMemory(MessageWindowChatMemory.withMaxMessages(10))
            .build();
            
        // The LLM analyzes the request, realizes it needs to call checkLimits() 
        // and verifyFraudRisk() first, aggregates the data, and returns a decision.
        String agentDecision = assistant.chat(userRequest);
        
        // Emit the final decision back to the event-driven stream
        kafkaTemplate.send("payment-execution-events", record.key(), agentDecision);
    }
}
Use code with caution.
